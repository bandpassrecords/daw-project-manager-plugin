DPM Companion — manual install

The .pkg installer next to this zip on the release page does this for you.
To install by hand, copy:

  DPM Companion.vst3       ->  /Library/Audio/Plug-Ins/VST3/
  DPM Companion.component  ->  /Library/Audio/Plug-Ins/Components/

(or the same folders under ~/Library for your user only), then rescan
plug-ins in your DAW.

Put it on your master bus. It needs DAW Project Manager installed to share
captures and to-dos: https://github.com/bandpassrecords/daw-project-manager
